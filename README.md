# rodrigosbessa.github.io

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro — sem frameworks, sem dependências.

## Stack

- **HTML/CSS/JS** — zero dependências
- **Google Fonts** — DM Mono + Syne
- **GitHub Pages** — alojamento gratuito

## Funcionalidades

- Animações de scroll via Intersection Observer API
- Cursor personalizado com estados de hover
- Efeito parallax no texto de fundo do hero
- Textura de ruído + overlay de scanlines
- Totalmente responsivo
